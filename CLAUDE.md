# Instructions for working in this repository

Personal academic site of Ryota Takatsuki, served by GitHub Pages at https://rtakatsky.github.io. Plain Jekyll built natively by GitHub Pages from `master`: no custom plugins, no JavaScript, no third-party assets, no CI.

## Where facts come from

- Every academic fact (positions, papers, talks, awards, dates, coauthors) comes from `~/Research/academic-portfolio`. Its `profile/` files are the single source of truth; each publication or presentation folder README holds the URLs (DOI, arXiv, OpenReview, code, event pages).
- Never invent facts, dates, links, or statuses. If the portfolio has a `[TODO]`, leave the item out or ask; never fill the gap yourself.
- `publications.md` and `assets/cv.pdf` are generated by `python3 scripts/sync-portfolio.py`. Never edit them by hand; change the portfolio and re-run the script.
- `index.md` and `_data/news.yml` are written by hand but must stay consistent with the portfolio.

## News

- Newest first. Link to the paper, code, or event page whenever the portfolio has a URL for it.
- Show a month when known and only the year when the month is not recorded.

## Language and style

- The site is English only; the Japanese name appears under the English name on the home page. Do not add translated pages.
- First person, concise, academic but plain. No hype, and stay neutral on machine consciousness.

## Design and security constraints

- No JavaScript, no external scripts, fonts, or images. The Content-Security-Policy meta tag in `_layouts/default.html` forbids inline styles, so put all styling in `assets/css/style.css`.
- Light and dark modes come from `prefers-color-scheme`; every color must be defined in both.
- Keep the single-column, text-first layout. Do not add a framework.
- Do not add GitHub workflows. Deployment is GitHub Pages building `master` directly.

## Building

- `scripts/serve.sh` (or `scripts/serve.sh build`) picks Homebrew's Ruby 3.3 and a UTF-8 locale. Ruby 4 must not be used: the Gemfile refuses it.
- Keep `theme: null` in `_config.yml`, otherwise GitHub Pages injects its default theme.
